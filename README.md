## Sobre o Projeto
Este repositório contém o código-fonte do **Protótipo Prático** desenvolvido para a disciplina de Paradigmas de Programação. O projeto consiste em uma aplicação de terminal para gerenciamento acadêmico, projetada com o objetivo central de investigar a seguinte questão:

> *"Kotlin substitui Java ou as duas linguagens continuarão coexistindo na JVM?"*
